# Code Cleaner Skill

## 목적
코드 정리 및 리팩토링 시 일관된 원칙 적용

## 트리거
- "코드 정리"
- "리팩토링"
- "정리해줘"
- "깔끔하게"
- "cleanup"
- "refactor"

## 핵심 철학
**"Less is More"** - 완벽한 코드는 더 이상 뺄 것이 없는 코드

## 역할 구분

### CLAUDE.md (평상시)
- 코드를 **작성**할 때 기본 원칙
- 새로운 기능 구현 시 방향성
- 프로액티브 가이드

### code-cleaner (요청 시)
- 기존 코드를 **정리**할 때 원칙
- 리팩토링 요청에 대한 대응
- 리액티브 실행

## 사용 예시
```
사용자: "이 프로젝트 코드 정리해줘"
→ code-cleaner 스킬 자동 활성화
→ YAGNI 원칙에 따라 불필요한 코드 제거
→ 중복 통합, 구조 단순화
```
