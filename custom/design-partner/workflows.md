# 용도별 전문가 워크플로우

이미지·영상 생성은 **단순히 프롬프트를 짜서 결과물을 받는 작업이 아니라**, 용도마다 누적된 전문가 파이프라인이 있다. 단계마다 만들어야 할 에셋과 점검 포인트가 정해져 있고, 그 순서를 따를 때 일관성·완성도가 확보된다.

이 문서는 디자인 파트너가 사용자의 용도를 파악한 후, 그에 맞는 전문 워크플로우의 단계로 진입시켜 진행하기 위한 카탈로그.

## 코치 역할 — 모든 워크플로우 공통

각 단계마다 디자인 파트너는 세 가지를 한다:

1. **현재 단계 명시**: "지금은 [X] 단계예요" — 사용자가 어디 있는지 인식
2. **이 단계에서 만들 에셋**: "이 단계에서는 [Y] 같은 산출물이 나와야 다음 단계로 갈 수 있어요"
3. **이 단계의 핵심 개념 한 가지**: 워크플로우를 따르며 자연스럽게 전문 어휘·판단 기준을 학습 — 매 단계 *왜 이 순서인지*를 짧게 설명

**용도가 뭔지 모호하면 진입 금지.** 캐릭터 시리즈를 단발 일러스트 워크플로우로 가면 일관성이 깨지고, 영상 키프레임을 단발 사진 워크플로우로 가면 컷 간 톤이 흐트러진다.

## Vault 통합 (사용자가 vault에서 작업하는 경우)

Vault CLAUDE.md의 "AI 이미지 생성 프롬프트 워크플로우" 정책에 따라 프로젝트 폴더 구조 자동 권장:

```
프로젝트/
├── moodboard/      ← 무드보드·레퍼런스
├── assets/         ← 캐릭터/환경 시트, 스타일 가이드
├── generated/
│   ├── trials/     ← 테스트 이미지
│   ├── selected/   ← 최종 선택
│   └── notes.md    ← 실패 원인·금지어·필수어 누적

```

작업 시작 시 `generated/notes.md` 먼저 읽기 — 이전 실패 이력이 다음 프롬프트 결정의 1차 입력.

# 워크플로우 카탈로그

## 1. Cinematic / 영상 제작

키프레임 → Veo 클립화 → 스티칭의 **기술적 파이프라인**은 [`video-workflow.md`](video-workflow.md)에 별도. 여기서는 그 **앞 단계(기획·에셋 준비)**에 집중.

### 단계

**Phase 0 — 기획 (Pre-production)**
- 한 줄 컨셉: 무엇을 보여주는 영상인가
- 톤 & 무드: 시청자가 느껴야 할 감정 (긴장 / 평온 / 유머 등)
- 타깃 길이: 8초·30초·1분+ — 길수록 컷 분할 필요
- **산출물**: 한 줄 로그라인 + 톤 키워드 3-5개

**Phase 1 — 스토리보드**
- 컷 단위 분할: 각 컷의 의도, 카메라 워크, 길이
- 시퀀스 흐름: 컷 간 연결성 (cut / dissolve / match cut)
- **산출물**: 컷 리스트 (텍스트 또는 러프 스케치) — 각 컷 1-2문장 + 카메라 노트

**Phase 2 — 비주얼 디벨롭먼트 (에셋 준비)**
- 무드보드: 색감·조명·질감 레퍼런스 모음
- 캐릭터 시트: 정면·측면·포즈·표정 (Nano Banana Pro 다중 ref용)
- 환경 시트: 주요 location의 와이드·미디엄·디테일
- 스타일 가이드: 컬러 팔레트, 광원 방향, 질감 키워드
- **산출물**: 다음 단계에서 reference로 입력할 이미지·텍스트 묶음

**Phase 3 — 키프레임 생성**
- 컷별 핵심 프레임을 이미지 생성 (Phase 2 에셋을 ref로 활용)
- 일관성 확인: 같은 캐릭터·광원·스타일이 모든 키프레임에 유지되는가
- **모델 선택**: 일관성 필수 → Nano Banana Pro (ref 14장) / 빠른 탐색 → Midjourney·NB2

**Phase 4 — 클립화 (Veo image-to-video)**
- 각 키프레임을 짧은 클립으로 (보통 8초)
- 카메라 모션 프롬프트 (pan / dolly / static)
- 비용 관리: Lite로 컨셉 검증 → Standard로 최종

**Phase 5 — 스티칭·후처리**
- FFmpeg로 클립 연결, 자막·BGM 추가
- 프레임 일관성 최종 검수 (조명·캐릭터·스타일)

### 코치 포인트

- 신규 사용자는 Phase 0-2를 건너뛰고 바로 키프레임을 만들려는 경향이 있음 → "에셋 없이 키프레임 가면 컷 간 일관성이 깨져요. 먼저 캐릭터 시트부터 만들어볼까요?"
- 핵심 어휘: shot list, blocking, continuity, hero shot, ref pack

## 2. Character Design

게임·애니메이션·일러스트에서 캐릭터 1명을 다양한 상황·포즈에서 일관되게 그리는 작업.

### 단계

**Phase 0 — 캐릭터 정의**
- 정체성: 이름·역할·세계관 위치
- 시각적 키워드: 3-5개 (예: "노쇠한 / 따뜻한 / 군청색 코트")
- **산출물**: 한 단락 캐릭터 설명

**Phase 1 — 컨셉 시트 (Concept Sheet)**
- 정면 + 측면 + 후면 (turnaround)
- 의상·소품 디테일
- **산출물**: 1-3장의 reference 이미지

**Phase 2 — 표정·포즈 시트**
- 5-8개의 표정 변형
- 주요 동작 포즈
- **산출물**: 다음 작업에 ref로 들어갈 표정/포즈 묶음

**Phase 3 — 컬러 팔레트 고정**
- 의상 컬러 4-5색 추출
- 피부톤·머리색 표준
- **산출물**: 컬러 팔레트 카드 (Nano Banana JSON `colorRestriction` 입력값)

**Phase 4 — 시리즈 적용**
- Phase 1-3 에셋을 ref로, 다양한 장면에서 캐릭터 등장
- Nano Banana Pro의 다중 ref + JSON 템플릿 적극 활용

### 코치 포인트

- 컨셉 시트 없이 매번 0부터 생성하면 같은 캐릭터가 다른 사람이 됨 → 에셋 재사용의 가치 강조
- 핵심 어휘: turnaround, model sheet, design DNA, silhouette test

## 3. Concept Art (게임·영화 프로덕션)

세계관·환경·핵심 비주얼을 정립하는 작업. 단발 일러스트가 아니라 **다른 아티스트가 받아 작업할 수 있는 가이드**가 결과물.

### 단계

**Phase 0 — 비주얼 브리프**
- 무엇을 컨셉하는가: 환경 / 프롭 / 캐릭터 / 키 비주얼
- 분위기·시대·기술 수준
- **산출물**: 1-2 단락 브리프

**Phase 1 — 무드보드**
- 레퍼런스 이미지 10-20장 (실사·게임·영화·아트북)
- 색·구도·디테일 키워드
- **산출물**: 무드보드 콜라주

**Phase 2 — 썸네일 다수 (Thumbnailing)**
- 작은 사이즈로 5-10가지 컨셉 빠르게
- 구도·실루엣·빛 위주, 디테일 무시
- **산출물**: 썸네일 시트 (Midjourney `--c` 높여서 다양성 확보)

**Phase 3 — 키 비주얼 발전**
- 가장 강한 1-2개 썸네일을 고해상도로 발전
- 라이팅·디테일·재질 묘사 추가
- **산출물**: 최종 키 비주얼

**Phase 4 — 분리 시트**
- 환경 / 캐릭터 / 프롭을 각각 분리해서 정리
- 다른 작업자가 활용할 수 있는 형태로 라벨링

### 코치 포인트

- 첫 번째 썸네일을 무조건 발전시키려는 함정 → "5개는 뽑아놓고 비교해야 좋은 게 보여요"
- 핵심 어휘: silhouette, value study, key art, callout

## 4. Photography (Editorial / Portrait / Fashion)

사진 시리즈. 단발 사진이 아닌 **컨셉을 가진 컷 리스트** 단위.

### 단계

**Phase 0 — 컨셉 정의**
- 스토리: 누가·어디서·왜
- 톤: editorial / candid / cinematic / studio
- **산출물**: 한 단락 컨셉 + 키워드

**Phase 1 — 무드보드**
- 조명·로케이션·의상 레퍼런스
- 동시대 사진가 스타일 참고 가능 (저작권 회피 — 직접 모방 금지)
- **산출물**: 무드보드

**Phase 2 — 컷 리스트 (Shot List)**
- close-up / medium / full-body / environmental
- 각 컷의 의도와 라이팅
- **산출물**: 5-10컷 리스트

**Phase 3 — 일관성 시리즈 생성**
- Midjourney `--sref` 또는 Nano Banana Pro 다중 ref
- 모델·의상·로케이션 톤 유지

### 코치 포인트

- 라이팅이 사진의 90%. 사용자가 "사진 같은 느낌"을 막연히 원하면 → "rim light / soft window / golden hour 어느 쪽이 가깝나요?"
- 핵심 어휘: rim lighting, golden hour, depth of field, shot list, editorial tone

## 5. Illustration (Editorial / Storybook / Cover)

내러티브가 있는 일러스트.

### 단계

**Phase 0 — 메시지 정의**
- 한 컷이 전달해야 할 핵심 의미
- 글이 있다면 글의 어느 지점을 시각화하나
- **산출물**: 한 줄 메시지

**Phase 1 — 스타일 픽**
- 회화 / 디지털 / flat / textured / line-heavy
- 레퍼런스 1-2장
- **산출물**: 스타일 키워드 + 레퍼런스

**Phase 2 — 러프 (Composition Sketch)**
- 구도·요소 배치만 빠르게
- Midjourney 텍스트 묘사 또는 NB2
- **산출물**: 3-5 러프

**Phase 3 — 디테일 발전**
- 가장 좋은 러프를 선택 후 고도화
- 컬러·텍스처·라인 디테일 추가

### 코치 포인트

- 메시지 정의 없이 시작하면 예쁘지만 의미 없는 그림 → "이 일러스트로 독자가 한 가지를 받아간다면 뭐죠?"
- 핵심 어휘: composition, focal point, negative space, vignette

## 6. Pattern / Texture

반복 가능한 모티프 디자인.

### 단계

**Phase 0 — 모티프 정의**
- 핵심 도형·요소 1-3개
- 분위기 키워드
- **산출물**: 모티프 묘사

**Phase 1 — 단일 타일 디자인**
- 대표 1장 생성
- **산출물**: 시드 타일

**Phase 2 — 컬러웨이 (Colorways)**
- 같은 패턴의 색상 변형 3-5종
- Nano Banana JSON `colorRestriction` 활용

**Phase 3 — 타일링 검증**
- 반복 시 이음새 자연스러운지 확인
- seamless tiling 키워드 포함

### 코치 포인트

- 한 장만 만들고 끝내려는 함정 → 패턴은 컬러웨이가 본체
- 핵심 어휘: motif, colorway, seamless tile, repeat unit

---

## 7. Product / Brand Visual

제품 사진·브랜드 비주얼.

### 단계

**Phase 0 — 브랜드 정의**
- 컬러 팔레트·타이포·voice
- 스튜디오 톤 / 라이프스타일 톤 / 둘 다
- **산출물**: 브랜드 가이드 한 장

**Phase 1 — 컨테이너 결정**
- 스튜디오 (배경 단순, 제품 강조)
- 라이프스타일 (사용 맥락, 인물·환경 포함)
- 둘 다 필요하면 두 트랙 병행

**Phase 2 — 다중 앵글 일관성**
- 정면·45도·디테일·used in context
- Nano Banana Pro 다중 ref로 통일

**Phase 3 — 환경 변형 (라이프스타일만)**
- 동일 제품, 여러 환경
- 광원 방향 통일 중요

### 코치 포인트

- 라이프스타일에서 인물이 너무 강해지면 제품이 사라짐 → 시선·구도가 제품을 향하게
- 핵심 어휘: hero shot, context shot, brand consistency, lifestyle vs studio
